Contractor / Mover Registration & QR Gate Access

Resident/MA registration, approval, deposit status, temporary digital pass, email/SMS delivery, security validation and gate-entry audit.

Purpose

This module digitises contractor and mover approval while preserving Pandan Valley's existing three-gate operation and allowing future integration with Homeplus LPR if API access is available.

Scope of this module

RegistrationResident or MA enters contractor, purpose, unit, vehicle and visit details.
ApprovalMA reviews request and deposit status.
Digital passSigned/expiring QR pass generated for the approved visit.
Email + SMSPass delivered using the selected notification channels.
Gate verificationSecurity scans with phone/tablet and sees approved details.
Entry auditArrival, validity and gate-use recorded for management.

AI usage in this module

AI can highlight unusual repeat contractor visits, abnormal access times and recurring unregistered-visitor patterns for review, but does not automatically deny legitimate access.

Hardware / site requirement

Existing gate PCs/tablets may be reusable. Phone camera scanning is preferred initially. Dedicated scanners are optional. Barrier/LPR hardware integration depends on Homeplus technical access.

Commercial assumptions

Homeplus/LPR API development is not included until API documentation and test access are confirmed. SMS usage charges are excluded from the development price.
